Setup [1]

To get started, import the Promotion Exports script into your project. You can either host a local copy yourself or load it directly from a CDN using a <script> tag.

Our exports provides several utility functions which are both exposed globally on 'window._communitySpotlight', and returned when locally imported.

Local Import (Bundled or Direct Usage)

async function importPromotionExports() {
  // If imported directly in your project:
  const csExports = (/* Insert Exports code here... */);

  // OR, if already loaded globally:
  const csExports = window._communitySpotlight;

  // Start the session
  await csExports.startSession();
}

CDN Import

<script src="https://cdn.jsdelivr.net/gh/Community-Spotlight/promotion-exports/dist/community-spotlight.js"></script>
// Access the global exports after the script loads
const csExports = window._communitySpotlight;

With a CDN import, you do not need to manually call startSession, it gets initialized automatically.

Displaying Promotions in HTML [2]

The exports register a custom HTML element called promo-space. When added to a page, it automatically displays a Promotion without requiring any additional JavaScript. You can also provide attributes to control what kind of Promotion gets displayed. 

<promo-space></promo-space>

The next section will discuss various attributes that can be added to a promo-space element.

Attribute Description
controls

Displays a control bar above the Promotion, providing additional controls and visual information.

type

Required. Specifies the type of Promotion to display. Accepted values are image, video, and html.

ratio

Required. Filters Promotions by aspect ratio. A list of supported aspect ratios is provided below.

length

Used only when type="video". Limits the maximum duration of videos that can be displayed. Accepted values are 5, 10, 15, and 30.

tags

Overrides the global tag list (explained later) and filters which categories of Promotions may be displayed. Provide a comma-separated list of valid tags.

width

Sets the width of the displayed Promotion.
height

Sets the height of the displayed Promotion.

Promotion Exports Utilities [3]

As previously mentioned, our exports provides several utility functions which are exposed globally on 'window._communitySpotlight' and returned when locally imported.

Now let's cover these utilities:

Function Description Arguments
startSession

Starts the Community Spotlight session.

 None.
setGlobalTagFilter

Sets the global tag filter used by all promo-space elements that do not specify a tags attribute. This filter determines which categories of Promotions are allowed to be displayed.

An array of category strings. A complete list of valid categories can be found in the Uploader.
getAllPromos

Returns an array containing all available Promotions in their raw format, including all associated metadata.

None.
randomPromotion

Returns a random Promotion matching the supplied filters. The returned object is sanitized, meaning unnecessary metadata has been removed.

  1. type Promotion type: image, video, or html [Required]
  2. ratio: Supported aspect ratio string
  3. tags: Array of category strings
  4. length: Maximum video length: 5, 10, 15, or 30
